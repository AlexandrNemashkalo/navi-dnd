# Игра с Codex

Нужен актуальный Codex CLI с `--ignore-user-config`, `--ephemeral` и выполненным `codex login`. Игра использует этот вход, отдельный API-ключ не нужен.

В меню настроек выбери «НЕЙРОНКА → Codex». «МОДЕЛЬ ИГРЫ», «МОДЕЛЬ МИРА» и «МОДЕЛЬ ГЕРОЯ» переключаются стрелками отдельно: Sol 6.1, Astra 6, Luna 6 (доступность зависит от аккаунта). Модель игры обслуживает ходы и триггеры, мира — концепцию и старт приключения, героя — создание и описание персонажа. Пустая настройка мира/героя наследует модель игры; пустая модель игры использует стандартную модель CLI, а не модель из личного config.toml. «ПУТЬ К CODEX» — `codex`, если он в PATH, иначе полный путь к codex.exe. Все значения сохраняются в `Storage/settings.json`.

«РАЗМЫШЛЕНИЕ CODEX»: начни со «СРЕДНЕ». «БЫСТРО» сокращает размышление, но соблюдение сложных правил следует проверить на своих сценариях. «ГЛУБОКО» полезно для сложных сцен, ответ дольше. Описание героя и починка JSON всегда используют `low`.

Правила мастера передаются через `model_instructions_file`, контекст хода — через stdin. Личные настройки CLI не загружаются, оболочка и веб-поиск выключены. Для действия подключаются только его игровые MCP-инструменты с разрешением вызова без отдельного подтверждения CLI; броски и выбор цели по-прежнему запрашивает сама игра. Ошибка запуска обязательного MCP-сервера останавливает запрос.

Запросы с MCP не повторяются автоматически после сетевого сбоя: инструменты могли уже изменить состояние или получить бросок игрока. Ошибка CLI не превращается в успешный ответ из промежуточного сообщения. Модель, глубина размышления и длительность записываются в `logs/ai_*.log`.

Для проверки на отдельном сохранении (реальный вызов модели):

```powershell
$env:NAVIDND_PROMPT_PROVIDER = 'codex'
$env:NAVIDND_CODEX_MODEL = 'gpt-6.1-sol'
$env:NAVIDND_CODEX_REASONING = 'medium'
dotnet test NaviDnD.PromptTests --filter 'FullyQualifiedName~InventoryPromptTests'
```

Другие сценарии: `InteractiveResponsePromptTests` — бросок атаки и выбор цели, `CombatPromptTests` — бой. Меняй фильтр для нужной проверки; не включай запись моков без необходимости. Один успешный сценарий не гарантирует правильность остальных: сравнивай время и игровые инварианты на одинаковых сценах.

Проверка 6 октября 2026 на `gpt-6.1-sol`: смена оружия прошла с `medium` и `low` (около 16 с в обоих случаях); атака с вызовом `roll_dice` — около 21 с; неоднозначная цель с `select_target` — около 22 с. Это единичные замеры с автоматическими ответами игрока, а не гарантия задержки или качества. На простой экипировке уменьшение размышления заметного выигрыша не дало; пока разумно оставить `medium`.
