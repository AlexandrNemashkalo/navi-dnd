# NaviDnD

Настольная ролевая игра с ИИ-мастером, тактической картой и картой мира. Сейчас используются правила D&D 5e. Мастер — Claude или OpenAI Codex.

**Лицензия:** бесплатно использовать, изучать и дорабатывать игру можно в некоммерческих целях с сохранением авторства. Продажа игры, изменённых сборок и коммерческое использование требуют письменного разрешения автора. Полные условия — [LICENSE](LICENSE); сторонние компоненты сохраняют свои лицензии.

Изменения текущей версии и порядок проверки обновления — [RELEASE_NOTES.md](RELEASE_NOTES.md). Этот файл также устанавливается рядом с игрой.

## Запуск на Windows

**Готовая игра (Windows x64):** скачай репозиторий (**Code → Download ZIP**) и распакуй. В папке `releases` открой [NaviDnD-Setup-win-x64.exe](releases/NaviDnD-Setup-win-x64.exe), выбери папку и нажми **Установить**. .NET включён в сборку, устанавливать его отдельно не нужно. Установщик создаст ярлык. Файлы `NaviDnD-payload.*` должны лежать рядом с установщиком: это части готовой игры, разделённые из-за лимита размера файлов GitHub.

Установи Codex CLI или Claude Code и войди в аккаунт. При первом запуске игра попробует найти оба клиента в PATH, стандартных папках и расширениях VS Code и сохранит пути. Если найден только Codex, он будет выбран автоматически. При необходимости исправь клиент и путь в **Настройках** (подробности ниже, пункт 5). Начальные модели: Codex — Sol 6.1 со средним размышлением, Claude — Opus 5.5; игра открывается в полноэкранном режиме. Затем выбери **Новая игра**. В готовой сборке `Storage/` и `logs/` создаются рядом с exe. Обновление через установщик сохраняет эти папки; перед обновлением закрой игру. Удаление: удали папку игры и ярлык; если нужны сохранения, сначала скопируй `Storage/`.

### Обновления

В главном меню выбери **Обновления** и подтверди клавишей Enter. Скачивание отображается в игре: прогресс, текущий файл и скачанные мегабайты; Esc отменяет загрузку. После проверки SHA256 игра закрывается, обновляется без отдельного окна установщика и запускается снова. Сохранения, настройки и модель Silero сохраняются; при ошибке замены файлов установщик возвращает прежние файлы. Наличие новой версии также проверяется в фоне при запуске. Логи проверки — `logs/updates.log`. Для первого перехода со старой версии скачай свежую сборку и установи поверх прежней, предварительно закрыв игру.

При запуске из исходников обновляй репозиторий через `git pull` и собирай заново.

Публикация новой версии: измени `Version` в `Directory.Build.props`, запусти `build-release.ps1`, закоммить исходники, `releases/` и `.gitlab/release.json`, затем отправь коммит и тег `v<версия>`. GitLab CI создаст релиз со ссылками на установщик и части игры. Для обновлений без авторизации проект должен быть публичным.

### Запуск из исходников

1. Установи [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0) и один из клиентов: [Codex CLI](https://developers.openai.com/codex/cli) или [Claude Code](https://code.claude.com/docs/en/quickstart). Нужен аккаунт с доступом к выбранной нейронке.
2. Скачай репозиторий и открой PowerShell в его папке.
3. Собери игру и сервер инструментов:

   ```powershell
   dotnet build NaviDnD.McpServer/NaviDnD.McpServer.csproj
   ```

4. Запусти игру в отдельном окне консоли:

   ```powershell
   Start-Process .\NaviDnD\bin\Debug\net9.0\NaviDnD.exe
   ```

5. В меню **Настройки** выбери нейронку. Укажи путь к её exe, если она не найдена в PATH, и доступные твоему аккаунту модели игры, мира и героя.
   - **Codex:** один раз выполни `codex login`. Отдельный токен в игре не нужен. Начни с Sol 6.1 и среднего размышления, если модель доступна аккаунту.
   - **Claude:** войди через `claude auth login` и оставь поле токена пустым либо получи токен по инструкции ниже.
6. Выбери **Новая игра** и создай персонажа.

Папки хранения и файл настроек создаются автоматически при первом запуске; сохранения, миры и герои — по мере игры. Данные находятся в `NaviDnD/Storage/`, логи — в `NaviDnD/logs/`. Обе папки исключены из Git. Перед пересборкой закрой игру.

### Как получить токен Claude для настроек игры

1. Установи [Claude Code](https://code.claude.com/docs/en/quickstart). Для токена нужна подписка Claude Pro, Max, Team или Enterprise.
2. Открой PowerShell и выполни:

   ```powershell
   claude setup-token
   ```

   Если команда не найдена, укажи путь к установленному exe: `& "C:\путь\к\claude.exe" setup-token`.
3. Открой предложенную ссылку в браузере, войди в аккаунт Claude и подтверди доступ. Если браузер покажет код подтверждения, вставь его в терминал.
4. Скопируй выданный терминалом OAuth-токен. В игре открой **Настройки**, выбери **Claude** и вставь его в поле **Токен Claude**. Настройки сохраняются автоматически.

Для этого поля нужен OAuth-токен от `setup-token`; ключ API из Anthropic Console сюда не подходит. Токен хранится локально в `Storage/settings.json`, исключённом из Git. Не публикуй этот файл и не отправляй токен другим людям. Если токен истёк, снова выполни `claude setup-token` и замени его в настройках. [Официальная инструкция](https://code.claude.com/docs/en/authentication#generate-a-long-lived-token).

## Управление

### Локальная озвучка

В настройках включи **Озвучку**. Используется локальный **Silero v5.5**. В пункте **Голос рассказчика** доступны **Айдар, Евгений, Бая, Ксения и Ксения 2**; при переключении звучит пробная фраза, выбор сохраняется. Для новых настроек по умолчанию выбран Айдар.

**Готовая сборка:** Silero, русская модель, Python и CPU PyTorch включены в установщик. При включении озвучки ничего не скачивается; системный Python и интернет не нужны. Комплект находится в `Speech/silero/`, пользовательские настройки — в `Storage/`. Для запуска из исходников без комплекта нужен Python 3.10–3.12 x64; установка: `powershell -NoProfile -ExecutionPolicy Bypass -File NaviDnD/Speech/setup-silero.ps1`. Для сборки автономного релиза кэш Silero должен использовать Python 3.12. Используется [Silero v5.5](https://github.com/snakers4/silero-models).

Громкость речи задаётся отдельно. **F11** останавливает речь; Enter и Esc также очищают очередь. Озвучиваются новые реплики без механических пометок; старые записи при открытии сохранения не читаются. Если звука нет, проверь статус в настройках и `logs/speech.log`.

При включённой озвучке ведущий передаёт один `text` с SSML-разметкой: на экране игра скрывает теги, ударения и смысловые выделения, а Silero получает паузы и настройки интонации. Флаг `speechEnabled:true/false` передаётся одной строкой в контексте; при выключенной озвучке ведущий присылает обычный текст. Отдельный дублирующий текст от нейронки не требуется. Если разметка некорректна, используется обычная речь. При запуске с включённой озвучкой модель загружается и прогревается в фоне без звука; в готовой сборке установка зависимостей при первом включении не требуется.

Стрелки — движение; текст + Enter — действие для мастера. F1 — тактическая карта, F2 — мир, F3 — журнал, F4 — персонаж; Esc — меню.

## Проверка кода

```powershell
dotnet test NaviDnD.Tests/NaviDnD.Tests.csproj
```

Не запускай тесты всего решения без необходимости: `NaviDnD.PromptTests` делает реальные запросы к нейронке и расходует лимиты/средства. Подробнее о Codex: [docs/codex.md](docs/codex.md).

## Обновление готовой сборки

Разработчику нужны .NET 9 SDK и Git. Из корня репозитория выполни `powershell -NoProfile -ExecutionPolicy Bypass -File build-release.ps1`. Скрипт соберёт игру, MCP-сервер и графический установщик со встроенным .NET, обновит части архива, exe и контрольные суммы в `releases/`. После изменения кода пересобери релиз. Игровые данные не включаются; ресурсы берутся только из файлов, отслеживаемых Git. Исходники и релиз хранятся в одном репозитории.

Промежуточные файлы релиза создаются в системной временной папке и автоматически удаляются после сборки, в том числе при ошибке.
