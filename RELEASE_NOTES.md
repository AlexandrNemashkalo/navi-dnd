# NaviDnD 2.2.6

- Настройки ИИ стали понятнее: статус подключения, аккаунт при доступности и одна кнопка для входа или настройки. Токен Claude можно задать или очистить; видно, когда он используется, само значение скрыто.
- Игра отличает Claude Desktop от Claude Code CLI. Если установлен только Desktop, показывает причину и кнопку с официальной инструкцией установки CLI; подходящий клиент находится автоматически.
- Уточнены направления в инструкциях мастеру: на локальной карте север сверху, юг снизу; координаты карты мира используют другую ось Y.
- Заполнение чанка больше не отклоняется из-за предмета на заблокированной клетке, если рядом есть безопасное место в той же комнате или на улице этого чанка.
- Изменён запуск нового окна на macOS при смене шрифта и режима экрана: приложение открывается через системный механизм, старое окно закрывается после успешной команды запуска.
- Ники в титрах открывают Reddit-профили по клику или Enter.

Патчи для Windows и macOS (Apple Silicon). Сохранения и настройки сохраняются.

## English

- Clearer AI settings: connection status, account details when available, and one button for sign-in or setup. The Claude token can be entered or cleared; the interface shows when it is in use and masks its value.
- The game distinguishes Claude Desktop from Claude Code CLI. Desktop-only installations show an explanation and a button linking to the official CLI installation guide; compatible clients are detected automatically.
- Clarified compass directions in GM instructions: north is up and south is down on location maps; world maps use a different Y axis.
- Chunk population no longer fails because an object was placed on a blocked cell when a nearby safe cell is available in the same room or outdoor section of that chunk.
- Changed macOS window relaunch after font or display-mode changes: the app launches through the system, and the old window exits after the launch command succeeds.
- Credit usernames open their Reddit profiles with a click or Enter.

Patches for Windows and macOS (Apple Silicon). Saves and settings are retained.
