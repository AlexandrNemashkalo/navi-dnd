# NaviDnD 2.0.6

- Добавлен поиск Claude Code из Claude Desktop, включая установку из Microsoft Store. Исправляется устаревший путь; приложение Desktop не принимается за CLI.
- При создании мира и описания героя показываются понятные причины: Claude не найден, вход не выполнен или истёк, у аккаунта нет доступа. Добавлены подсказки по исправлению.
- В настройках накопленный ввод обрабатывается перед отрисовкой, обновляются только изменившиеся строки — устранена задержка стирания пути при удержании Backspace.

Обновление распространяется патчем; сохранения и настройки сохраняются.
