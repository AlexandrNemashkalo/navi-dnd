# NaviDnD 2.0.3

- В установщике появилась полоса прогресса: подготовка архива, распаковка игры, установка файлов и применение обновлений.
- Установка базы быстрее: распакованные файлы переносятся в папку игры, а не копируются второй раз.

Обновление из игры в этот раз снова скачивает новый установщик (около 50 МБ): им обновляется помощник `Updater/`.

## Как проверить

1. Скачай ZIP по ссылке «📦 Скачать NaviDnD», распакуй и запусти `releases/NaviDnD-Setup-win-x64.exe`.
2. После нажатия «Установить» под кнопкой заполняется полоса, подпись показывает текущий этап.
