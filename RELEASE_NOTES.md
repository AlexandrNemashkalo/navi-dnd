# NaviDnD 2.0.8

- Codex использует общий автопоиск CLI при запуске запроса: устаревший путь заменяется найденной установкой из PATH, npm или расширения редактора. Claude остаётся провайдером по умолчанию.
- При отсутствии авторизации или истёкшем входе Codex показывает понятное сообщение с командой codex login, в том числе при создании мира и описания героя.
- Отдельно показываются отсутствие CLI, запрет запуска, отсутствие доступа к модели и исчерпание лимита; ошибки авторизации не вызывают автоматических повторных запросов.

Обновление распространяется патчем; сохранения и настройки сохраняются.
