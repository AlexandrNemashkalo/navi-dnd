# NaviDnD 2.2.3

- Исправлено: повторные клики по ярлыку, пока игра запускалась, открывали несколько копий игры сразу — с озвучкой это могло занять всю память компьютера. Теперь игра всегда одна: новый запуск выводит вперёд окно уже открытой игры.
- Окно игры при запуске всегда появляется поверх остальных, а не позади них.
- Настройки консоли Windows при одновременных запусках больше не меняются.

Обновление распространяется патчем; сохранения и настройки сохраняются.

## English

- Fixed: clicking the shortcut again while the game was starting opened several copies at once — with voice-over this could take up all of the computer's memory. Now only one copy runs: launching again brings the open game window to the front.
- The game window now always opens on top of other windows, not behind them.
- Windows console settings are no longer changed by simultaneous launches.

The update is delivered as a patch; saves and settings are kept.
