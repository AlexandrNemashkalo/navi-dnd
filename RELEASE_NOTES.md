# NaviDnD 2.0.2

- Окно установщика подстраивается под масштаб Windows: при 150–200% кнопка «Установить» и флажки больше не обрезаются.

Обновление из игры в этот раз скачивает и новый установщик (около 50 МБ): им обновляется помощник `Updater/`.

## Как проверить

1. Поставь масштаб Windows 150% или больше (Параметры → Система → Дисплей → Масштаб) и запусти `NaviDnD-Setup-win-x64.exe`.
2. Окно целиком помещается: видны поле папки, оба флажка и кнопка «Установить».
