# NaviDnD 1.1.4

Автономная озвучка в готовой сборке.

- В установщик включены переносимый Python 3.12, CPU PyTorch, NumPy и русская модель Silero v5.5.
- При включении озвучки ничего не скачивается; установка системного Python не нужна.
- Сохранены пять голосов, настройки и прогрев модели. Ранее скачанный комплект в Storage не удаляется.

## Как проверить

1. Обнови игру до версии 1.1.4 через «Обновления» либо установи свежую сборку поверх старой.
2. Подтверди обновление клавишей Enter. Внизу меню появится прогресс скачивания; Esc отменяет загрузку.
3. После скачивания и проверки файлов игра автоматически обновится и запустится снова.
4. Включи озвучку и переключи голос рассказчика: пробная фраза должна звучать без скачивания модели и настройки пути к Python.
