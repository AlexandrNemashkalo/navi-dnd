# Alacritty со сменой указателя

Для NaviDnD.app используется Alacritty 0.17.0, исходный коммит `94e7c8874e526b1e67b349d9ba30ddf81669119e`, с локальным патчем `alacritty-osc22.patch`. Лицензия исходников и патча — Apache-2.0. Основа протокола: [предложение OSC 22 в Alacritty](https://github.com/alacritty/alacritty/pull/7244); патч адаптирован к 0.17.0 и хранит состояние указателя в модели терминала, используя существующее событие `MouseCursorDirty`.

Игра уже отправляет `OSC 22;pointer` и `OSC 22;default`. Патч передаёт выбранный указатель оконной библиотеке Winit, которая устанавливает нативный курсор macOS. Настройка `terminal.osc22` по умолчанию выключена и включается в нашем `alacritty.toml`. Указатель применяется только при включённом мышином режиме, вне vi mode; сбрасывается командой RIS и выключением настройки. Подсказки ссылок и служебные кнопки терминала сохраняют приоритет своих указателей.

## Сборка в CI или на Mac

Ветка `build-macos-cursor` запускает `.gitlab/alacritty-ci.yml`: обычный Linux runner собирает Mach-O arm64 через cargo-zigbuild 0.23.4 и macOS 11.3 SDK. Образ закреплён SHA256; артефакт и журнал публикуются в Generic Package Registry `navidnd-alacritty/<коммит>/`. SDK в игру не включается. Тесты ядра исполняются на Linux; нативную смену указателя проверяют на Mac после установки обновления.

Для нативной сборки на Mac нужны Xcode Command Line Tools, rustup, Git и Python 3. Скрипт устанавливает закреплённую версию Rust 1.85.0 и целевую платформу Apple Silicon, выполняет тесты ядра терминала и собирает приложение:

```bash
bash macos/build-alacritty.sh
```

Результат: `artifacts/macos-cache/alacritty-custom/` с файлами `alacritty`, `alacritty-LICENSE` и `build.json`. Для релиза ссылка и метаданные успешного CI-артефакта закрепляются в `macos/alacritty-build.json`: обычный `build-macos.ps1` скачивает его автоматически при отсутствии подходящего кэша. Локальный бинарник не заменяет закреплённый артефакт. Упаковщик проверяет исходный коммит, версию Rust, SHA256 патча и бинарника, а также заголовок Mach-O arm64. Если патч изменился, терминал нужно пересобрать. Старый бинарник из официального `.dmg` не используется.

Тесты в патче проверяют настоящие последовательности OSC 22 с окончаниями BEL и ST, возврат к стрелке, выключение мышиного режима, vi mode, RIS, отключённую настройку и неизвестное имя указателя.

## Проверка на Mac перед выпуском

Открой собранную NaviDnD.app. Проверь руку над кнопками меню и объектами карты, возврат к стрелке на пустой области, ввод текста, выход указателя из окна и возвращение, сворачивание и повторное открытие. Затем закрой игру и проверь указатель в других приложениях. Автоматические тесты протокола не заменяют эту проверку нативного указателя.

Текущий Windows-релиз использует официальный Alacritty и собственный Win32-механизм курсора; этот патч нужен только пакету macOS.
