# Собственные изображения

Текущая партия из 100 новых изображений: `generation-batches/hundred-20261107/`.
Проверенные игровые файлы `batch100-*.png` — настоящие PNG 32×32, подготовленные
из отдельно сохранённых результатов встроенного image_gen. Они отображаются
в разделе **«Свои генерации · 32×32»** (`#generated`) и привязаны к 19 предметам,
22 видам мест/биомов и 59 существам. В provenance указаны исходные размеры,
подготовка, промпт и хеш; отклонённый `batch100-sea-horse-v1` не публикуется.
Промпты каждого вызова находятся в JSON-файлах `results/` внутри папки партии,
а `review.json` связывает визуальную проверку с точными хешами итоговых PNG.

Ранние четыре образца BG3 сохранены здесь как архив эксперимента. Они больше не подменяют предметы и не входят в действующую галерею. Подготовленные иконки только для заклинаний находятся в [`../bg3-spells/`](../bg3-spells/); порядок подготовки и подключения описан в [основном README](../../README.md).

Конвертер для своей иконки (Pillow):

```powershell
python scripts/icon_to_braille.py input.png artifacts/my-icon --mode auto --size 64
# Для светлых контуров BG3 с рамкой:
python scripts/icon_to_braille.py input.png artifacts/my-icon --mode lines --inset 5 --threshold 115
```

Результат: `my-icon.mask.png` — строго ч/б геометрия; `my-icon.color.png` — исходный RGB только на линиях; `my-icon.background.png` — сглаженный фон с мягкими прозрачными краями; `my-icon.html` — отдельное техническое сравнение оригинала, линий и варианта с фоном (не часть арт-библиотеки). `lines` сохраняет готовые штрихи, `edges` выделяет тонкие границы залитых форм, `auto` выбирает по заполненности. `--inset` убирает рамку, `--threshold` задаёт контраст штрихов, `--edge-threshold` — чувствительность границ. Мелкие отдельные точки отбрасываются; повторная запись требует `--force`. На сложных рисунках режим и порог нужно подбирать по превью.

Фон — спокойный нейтральный градиент с едва заметным оттенком линий. Текстура, пятна и локальное свечение оригинала не переносятся. `--background-feather 6` задаёт ширину перехода к панели в пикселях подложки. У исходника без фона новый фон не создаётся. В игре подложка независимо заполняет всю область картинки по ширине и высоте: стандартно 36×18 символов (72×72 точки), а символ 64×64 остаётся в исходном масштабе по центру. Один символ Брайля содержит 2×4 точки, один цвет линий и один цвет подложки: цвет линий усредняется только по включённым точкам, фон отдельно — с учётом прозрачности. Это градиент между ячейками терминала; внутри одного символа фон однотонный. Карточки заклинаний читают слои, перечисленные в `RuleSets/Dnd5e/spell-icons.json`. Обычный вывод предметов не принимает подготовленные `*.mask.png`. Прозрачные края смешиваются с текущей темой при отрисовке, цвет панели не записывается в PNG и не фиксируется в кэше.

Изображения, созданные для проекта, отдельно от сторонних паков.

- `gandalf-32x32.png` — экспериментальный портрет Гэндальфа, PNG RGBA 32×32 с прозрачным фоном. Происхождение и SHA-256 записаны в `gandalf-32x32.provenance.json`.

Добавление в эту папку само по себе не означает художественного одобрения или подключения к игровому подборщику.

Пейзажи с видом на горизонт (PNG RGBA, ровно 32×32, назначение `biome_view`):

- `sea-horizon-32x32.png` — море.
- `grass-horizon-32x32.png` — травяная равнина.
- `hills-horizon-32x32.png` — холмы.
- `mountains-horizon-32x32.png` — горы.

Для каждого пейзажа рядом сохранён файл `.provenance.json`. В галерее выберите пак «Собственные изображения» и режим всех изображений: пейзажи не входят в раздел «Лица».

Исходные большие пейзажи сохранены в `generation-sources/`. Финальные пейзажи получены усреднением ячеек сетки 32×32 (BOX) и сведением к 16 цветам без дизеринга. Воспроизводимая обработка: `python scripts/pixelize-art.py input.png output.png --size 32 --colors 16`. Выходной файл должен быть новым; скрипт предназначен для непрозрачных изображений и работает на Windows/macOS с Pillow.

Символьные варианты `sea-symbol-32x32.png`, `grass-symbol-32x32.png`, `hills-symbol-32x32.png`, `mountains-symbol-32x32.png` построены из SVG в `000000`: строго 32×32, два цвета, без сглаживания. Исходники не изменяются. Пересборка: `python scripts/build-own-landscape-symbols.py` (Pillow и resvg-py, общий код Windows/macOS; проверено на Windows). Исходные авторы: Icons made by Lorc (море, горы) and Delapouite (трава, холмы), CC BY 3.0; см. `src/icons/license.txt`. Пути и хеши исходников сохранены в `.provenance.json`.
