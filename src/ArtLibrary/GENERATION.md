# Обязательные критерии генерации

Генерируем готовый игровой пиксельный рисунок **32×32**, а не большую иллюстрацию
с эффектом пикселизации. Только после проверки добавляем его в каталог и подборки.

- Композиция рисуется на сетке ровно 32 столбца × 32 строки. Вся детализация
  укладывается в 1024 пикселя; каждый пиксель имеет один цвет.
- Итоговый файл — PNG ровно 32×32. Большое изображение с мелкими квадратными
  мазками не соответствует требованию, даже если запрос содержал «pixel art».
- Большой результат генератора нельзя выдавать за исходник 32×32. По запросу
  пользователя разрешена отдельная программная подготовка: nearest-neighbor
  до 32×32, бинарная прозрачность и ограниченная палитра без дизеринга.
  Исходник сохраняется отдельно, преобразования явно записываются в provenance.
  Нечитаемая после подготовки композиция бракуется, а не маскируется сглаживанием.
- Увеличенный просмотр допустим только как точное целочисленное nearest-neighbor
  отображение исходных 32×32, без дополнительной детализации внутри пикселей.
- Стиль проверяется рядом с новыми портретными паками: палитра, контраст,
  пиксельные группы и плотность деталей. Проверяем прежде всего при размере 32×32.
- Вид места или биома — взгляд с уровня стоящего человека, с читаемым горизонтом
  и глубиной сцены. Море, луг, лес и подобные виды не заменяются текстурой сверху.
  Небо и дальний план являются частью рисунка; удалять их как «фон» не нужно.
- Портреты и отдельные предметы используют прозрачность там, где нет объекта.
  Пейзаж может заполнять весь квадрат.
- Проверяем фактические размеры файла и видимое содержимое. Сохраняем промпт,
  инструмент, исходник, преобразования и SHA-256. Проверка размера сама по себе
  не подтверждает качество рисунка или его соответствие стилю.
- Если инструмент выдаёт больший файл, в каталог допускается только отдельно
  подготовленный и визуально проверенный PNG 32×32. Размер сам по себе не является
  художественным одобрением; крупный исходник остаётся вне игровой галереи.

Два первых больших пейзажа моря и луга, сгенерированные 2026-11-06, отклонены
пользователем: имитация пиксельной стилистики не соответствует настоящим 32×32.
Их не импортировать и не использовать как основу через уменьшение.

## Обязательная часть промпта

> Native 32×32 pixel-art game asset. Exactly 32 columns and 32 rows, 1024 pixels
> total, one flat color per pixel. Design every shape at that resolution.
> No high-resolution illustration, no faux pixelation, no subpixel details,
> no antialiasing, no smooth gradients. A larger preview may only be an exact
> nearest-neighbor enlargement of the original 32×32 grid. Match the supplied
> portrait-pack style references. Deliver the actual 32×32 PNG before catalog import.

Этот текст — требование, а не гарантия возможностей генератора; результат
обязательно проверяется отдельно.
