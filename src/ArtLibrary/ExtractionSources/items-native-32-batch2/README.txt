1824 PNG 32x32. Порядок наборов соответствует приложениям, внутри — слева направо, сверху вниз.
Предметы имеют прозрачный фон. Цветной рисунок навыков сохранён.
Извлечение по исходной пиксельной сетке, без изменения размера силуэта и без удаления чёрной обводки.
Источники — публичные увеличенные превью тех же изображений; JPEG-компрессия не позволяет восстановить точную исходную палитру PNG. Происхождение указано в manifest.json.
Галерея index.html работает локально в Windows и macOS.
