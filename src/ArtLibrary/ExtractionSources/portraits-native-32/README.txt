ПОРТРЕТЫ 32×32 — ИЗВЛЕЧЕНИЕ ПО ИСХОДНОЙ ПИКСЕЛЬНОЙ СЕТКЕ

384 отдельных PNG с прозрачным фоном: 8 наборов по 48 персонажей.
png/elves — исправленные эльфы из первого листа.
Остальные папки соответствуют семи новым листам в порядке пользователя:
humans, halflings, dark-elves, undead, demons, pirates, dwarves.
Нумерация в каждом наборе: слева направо, сверху вниз.

Открыть index.html для просмотра с белым, чёрным, синим и шахматным фоном.
previews содержит контактные листы. Фон контактного листа не входит в отдельные PNG.

В этой версии:
- Используются совпадающие публичные превью исходных листов, без перерисовки imagegen.
- Восстановлена сетка 32×32: шаг исходного увеличенного пикселя 5,2 px.
- Цвет берётся из центра каждого исходного пикселя, с подавлением JPEG-шума внутри него.
- Удаляется плоский коричневый фон плитки; тёмная обводка персонажа сохранена.
- Не срезается слой контура, не сжимаются силуэты до 30×30.
- Сохраняются отдельные аксессуары; несколько раздельных частей допустимы.
- Прозрачность строго 0/255, цвет полностью прозрачных пикселей обнулён.

Это извлечение из сжатых превью, а не исходные PNG пака: точную авторскую палитру
после JPEG-сжатия восстановить невозможно. Список источников — sources.json.
Исходники и воспроизводимый экспорт сохранены в work/ в рабочем каталоге.
PNG одинаково читаются на Windows и macOS; отображение внутри игры не проверялось.
